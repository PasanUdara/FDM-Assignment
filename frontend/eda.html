This page documents the visual checks performed on the credit-risk dataset: data quality, distribution shape, outliers, target balance, and feature relationships.

DATA QUALITY & DISTRIBUTIONS

Inspecting completeness and shape

These checks identify variables requiring cleaning or transformation before the model-development stage.

Missing values

Missingness was reviewed before median imputation for numeric fields and an Unknown category for selected categorical fields.

Numeric distributions

Distribution plots help reveal skewed fields and extreme values that should be considered during preprocessing.

Outlier review

Box plots provide a clear view of unusually high or low observations across the numerical variables.

Categorical distributions

Category counts help assess the prevalence of applicant characteristics and loan purposes.

TARGET & RELATIONSHIPS

Checking the prediction target and features

Class balance and feature correlation guide the training, validation, and interpretation strategy.

Loan-status class balance

The target distribution was inspected so evaluation uses metrics beyond accuracy, including ROC-AUC and recall.

Correlation heatmap

Correlation analysis highlights linear relationships among the numerical input variables.

Outcome: the EDA findings informed duplicate removal, sensible range filtering, missing-value treatment, one-hot encoding, feature engineering, and stratified train/test splitting.
